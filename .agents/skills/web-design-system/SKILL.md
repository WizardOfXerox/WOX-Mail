# Web Design System & Modern UI Intelligence

## 1. Core Principles
- Clarity First: Every component communicates its state (idle, hover, active, focus, disabled, loading).
- Hierarchy & Spacing: 4px/8px modular grid. Line-height 1.5-1.6 for body, 1.1-1.25 for headings.
- Micro-Interactions: Smooth 150-250ms transitions with ease-out curves.
- Accessible Contrast: WCAG 2.2 AA minimum (4.5:1 for body text, 3:1 for UI borders/icons).

## 2. Token Architecture
- Font Stack: Headings: 'Outfit', sans-serif; Body: 'Inter', sans-serif; Code: 'JetBrains Mono', monospace.
- Dark Theme: Page: #0b0c16, Card: #141528, Elevated: #1d1e38, Border: rgba(255,255,255,0.08), Primary: #7c3aed, Glow: rgba(124,58,237,0.3).
- Light Theme: Page: #f8f9fc, Card: #ffffff, Elevated: #f1f3f9, Border: rgba(0,0,0,0.08), Primary: #6d28d9, Glow: rgba(109,40,217,0.2).
