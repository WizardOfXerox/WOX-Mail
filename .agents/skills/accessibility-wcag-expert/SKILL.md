# Accessibility (WCAG 2.2 AA) Guide

## 1. Standards
- Minimum text contrast ratio: 4.5:1 for normal text, 3:1 for large text (18pt+ or bold 14pt+).
- Interactive target minimum size: 44x44px.
- Visible focus rings with 2px solid primary color and 2px offset.
- aria-live="polite" for dynamic message counter and auto-sync notifications.
- Complete keyboard navigability without mouse dependency.
