# Task Master — AI-Powered Task Management & Workflow Orchestration

Task Master structures complex programming objectives into decomposed, trackable execution phases, preventing context decay and ensuring 100% completion of requirements.

## Lifecycle Phases:
1. **Requirements Analysis**: Extract explicit and implicit requirements from user input.
2. **Architecture & Design**: Plan dependencies, data flows, and impact radii before modifying code.
3. **Task Decomposition**: Break goals into atomic, testable milestone steps.
4. **Execution & State Tracking**: Update task progress, verify invariants at each milestone, and adaptively handle edge cases.
5. **Final Validation**: Ensure all acceptance criteria and edge cases are validated.
